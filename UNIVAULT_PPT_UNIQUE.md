# Slide 2 — Problem Statement

**The problem with current ecommerce systems**

- Users **cannot easily find nearby stores** that sell what they need.
- **Delivery delays** and dependency on centralised warehouses.
- **Limited integration** between local shops and online shopping.
- **No hyperlocal product discovery** — hard to “shop from stores near me” on one platform.

**Image Suggestion:** User on phone or laptop searching for nearby shops on a map, looking frustrated or confused.

# Slide 3 — Existing Platforms

**Current solutions: Amazon & Flipkart**

- **Amazon** and **Flipkart** dominate online shopping in India.
- **Limitations:**
  - Focus mainly on **warehouse-based delivery**.
  - **No hyperlocal store discovery** — users cannot see nearby physical stores on a map.
  - **Limited local store visibility** — small shops are not part of the shopping flow.
  - Users **cannot easily find “which shop near me has this product”** or get directions.

# Slide 4 — Proposed Solution

**Univault Platform**

- **Hyperlocal shop discovery** — find real stores near the user.
- **Map-based product search** — see shops and products on an interactive map.
- **AI recommendation system** — get product suggestions (e.g. “best smartwatch under ₹3000”).
- **Local Mart integration** — browse nearby shops, filters, and shop details in one place.
- **Smart navigation** — drive, bike, and walk routes to selected shops.

# Slide 5 — System Architecture

**High-level architecture**

- **Frontend Web Interface** — HTML, CSS, JavaScript (product browse, cart, wishlist, map UI).
- **AI Search System** — natural-language product queries and recommendations.
- **GeoJSON Shop Database** — real shop locations and metadata for the map.
- **Map Engine** — Leaflet.js + OpenStreetMap / CartoDB tiles for rendering and interaction.
- **Product Recommendation Engine** — logic and data behind AI suggestions and filters.

**Image Suggestion:** Diagram with blocks: User → Frontend → AI Search | Map Engine | Product Engine → GeoJSON / Product Data.

# Slide 6 — Core Features

**Key features of Univault**

- **AI Shop Assistant** — ask in natural language and get product recommendations.
- **Local Mart Map Discovery** — view nearby shops on a map with categories and distance.
- **Product Category Search** — browse by category and see which local shops have stock.
- **Route Navigation** — turn-by-turn directions (drive, bike, walk) to chosen shops.
- **Wishlist and Cart System** — save favourites and add to cart like standard ecommerce.
- **Smart Filters** — radius, category, rating, and product-based filters.
- **Real-time shop discovery** — shops loaded from GeoJSON; distance calculated from user location.

# Slide 7 — Map Based Shopping (Unique Feature)

**Local Mart — Map-based shopping**

- **Show nearby shops on a map** — pins for each shop; clusters when zoomed out.
- **Filter by product category** — e.g. grocery, electronics, pharmacy, bakery.
- **Show shop details** — name, category, rating, distance, open/closed.
- **Navigate using integrated routing** — OSRM-based routes with drive, bike, and walk options.
- **Compare shops by distance** — list sorted by distance; choose best option and get directions.
