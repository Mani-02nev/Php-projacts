Univault Project Report

Complete Technical Documentation for Development Team

1. Project Overview

Univault is a fully functional, lightweight e-commerce platform built effectively using PHP and flat-file CSV storage. The project demonstrates a complete online shopping experience—from product browsing to secure checkout—without requiring a complex SQL database setup. It focuses on performance, simplicity, and a modern user interface.

2. System Architecture & Workflow

The system follows a standard Client-Server architecture where the PHP backend processes requests, interacts with the file-based database (CSV files), and serves dynamic HTML content to the client.

Workflow Explanation

  1. Request Handling: When a user accesses a page (e.g., index.php), the PHP server intercepts the request.
  2. Data Retrieval: The application uses custom helper functions (read_csv) in includes/functions.php to fetch data from data/products.csv.
  3. Session Management: User-specific data (Cart items, Wishlist, Login status) is managed using PHP Sessions ($_SESSION), ensuring data persists as the user navigates different pages.
  4. Rendering: The server processes this data and merges it with HTML templates to produce the final webpage.
  5. Data Persistence: When a user registers or places an order, the system writes the new data securely back to users.csv or orders.csv.

3. Technology Stack

Frontend (Client-Side)

  • HTML5 Semantic structure for accessibility and SEO.
  • CSS3 Custom styling with a focus on responsiveness (Flexbox/Grid).
  • JavaScript Vanilla JS for client-side interactivity and AJAX operations.

Backend (Server-Side)

  • PHP Core server-side language using modular functions and session management.
  • File System I/O Direct file manipulation for reading/writing database records.

Database (Storage)

  • CSV products.csv for inventory.
  • CSV users.csv for authentication.
  • CSV orders.csv for transaction capability.

4. Key Functionalities

🛒 Product Catalog

Products are dynamically fetched from the CSV database and displayed in a responsive grid. Includes category filtering and detailed views.

🔐 User Authentication

Secure registration and login system. Passwords are hashed using password_hash() before storage. Session-based authentication keeps users logged in.

❤️ Shopping Cart & Wishlist

Persistent State: Cart and Wishlist data are stored in PHP Sessions, allowing users to browse continuously without losing selected items.

AJAX Integration: The Wishlist feature uses asynchronous JavaScript calls to api/wishlist_toggle.php, providing instant feedback (heart animation) without a page reload.

💳 Checkout System

Compiles cart data, calculates totals, and creates a permanent order record in orders.csv. Automatically manages inventory by decrementing stock upon successful order placement.
